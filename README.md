# 🎂 Happy Birthday Aunty ❤️

A premium interactive birthday card created with HTML, CSS, and JavaScript.

## ✨ Features

- 🎁 Interactive gift opening
- 💖 Funny "YES / NO" surprise
- 📸 Photo slideshow
- 💌 Animated birthday letter
- 🎊 Confetti, balloons, and fireworks
- 📱 Responsive design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
